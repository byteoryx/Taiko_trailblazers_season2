# TAIKO-TRAILBLAZERS: SEASON2

## Установка Python 3.10 и pip 3.10 на Ubuntu

### Шаг 1: Обновите систему

Перед началом установки рекомендуется обновить системные пакеты:

```bash
sudo apt update && sudo apt upgrade -y
```

### Шаг 2: Установите зависимости
Для успешной установки Python 3.10, вам потребуются некоторые зависимости:

```bash
sudo apt install software-properties-common -y
```

### Шаг 3: Добавьте PPA для Python 3.10

Добавьте репозиторий, содержащий Python 3.10:
```bash
sudo add-apt-repository ppa:deadsnakes/ppa
```

 ### Шаг 4: Установите Python 3.10
После добавления репозитория, установите Python 3.10:

```bash
sudo apt update && sudo apt install python3.10 -y
```

### Шаг 5: Установите pip для Python 3.10
После установки Python 3.10, вам нужно будет установить pip:

```bash
sudo apt install python3.10-distutils
curl -sS https://bootstrap.pypa.io/get-pip.py | sudo python3.10
```

### Шаг 6: Проверьте установки
Убедитесь, что Python 3.10 и pip 3.10 установлены правильно:

```bash
python3.10 --version
pip3.10 --version
```

## Установка и запуск скрипта

### Шаг 1: Клонируйте репозиторий
Клонируйте репозиторий `taiko-trailblazers` на ваш сервер:

```bash
git clone git@github.com:cyberomanov/taiko-trailblazers.git
cd taiko-trailblazers
```
### Шаг 2: Откройте окно tmux
Чтобы ваш скрипт продолжал работу на сервере после вашего от него отключения, нужно использовать tmux.

```bash
tmux new -s taiko-trailblazers; tmux attach -t taiko-trailblazers
```

Этой же командой вы можете подключаться к старому окну, чтобы наблюдать за прогрессом.
### Шаг 3: Создайте и активируйте виртуальное окружение

```bash
python3.10 -m venv env && source env/bin/activate
```
### Шаг 4: Установите зависимости
Убедитесь, что у вас установлен pip для Python 3.10. Затем установите необходимые зависимости:

```bash
pip3.10 install -r requirements.txt
```

### Шаг 5: Настройка конфигурации
Откройте файл `user_data/config.py` в любом текстовом редакторе и настройте параметры согласно вашим требованиям.
<br><br>Создайте файл `user_data/private.txt` и добавьте в него ваши приватные ключи, прокси и адреса депозитов на биржи.
<br><br>Создайте файл `user_data/rhino.txt` и добавьте в него ссылки на контракты (https://app.rhino.fi/realm/trackers/TAIKO/deploy-and-interact).
Если вы не планируете использовать rhino_gm, вы можете оставить файл пустым.

### Шаг 6: Настройка тиров

В файле `user_data/tiers.py` вы можете настраивать различные тиры для аккаунтов.

Тиры нужны для того, чтобы распределить аккаунты в группы с разными лимитами по сжиганию газа.

При инициализации аккаунтов скрипт попросит ввести тир добавляемых аккаунтов: A, B или C.

### Шаг 7: Инициализация базы данных
Запустите скрипт `sql_add.py`, чтобы инициализировать базу данных:

```bash
python3.10 sql_add.py
```

После успешной отработки скрипта, у вас появится файл `data/data.db`, 
который вы можете открывать и просматривать прогресс в SQLite3 или в любом удобном инструменте-аналоге.
### Шаг 8: Настройка сетей для бриджей

В файле `user_data/chains.py` вы можете включать/выключать сети, редактировать rpc:

- `source_chains` - сети, из которых бот будет бриджить баланс в тайко;
- `destination_chains` - сети, в которые бот будет выводить баланс из сети тайко после окончания цикла.

Разные списки реализованы для того, чтобы контролировать сети, в которых остаётся баланс после отработки скрипта.
Я, например, вывожу баланс сразу на OKX, но ни в тайко, ни, например, в скролле, OKX депозиты не принимает.

### Шаг 9: Запуск основного скрипта
После настройки конфигурации и инициализации базы данных, запустите основной скрипт `trailblazers.py`:

```bash
python3.10 trailblazers.py
```

### Шаг 10: Экспорт data.db в data.csv
Для удобного просмотра data.db файл можно экспортировать в data.csv:

```bash
python3.10 export_csv.py
```

## TIERS

В софте предусмотрено несколько тиров, которые помогут распределить аккаунты на группы по затратам.
Во всяком случае, такова идея этой фичи.
<br><br>Например, вы хотите сделать группу определённых кошельков очень жирными и затратными, 
тогда вы можете включить все дорогие минты нфт и выбрать дорогие мосты.
<br><br>Или же сделать тир совсем ботов, у которых будет по 100 транзакций `wrap/unwrap` и никаких нфт.
<br><br>Для этого всего и существуют тиры, где можно разобрать аккаунты на выбранные вами категории.
<br><br>Далее мы рассмотрим каждый параметр. В модулях я указываю примерные затраты на транзакцию.

```python
TierItem(
    common=CommonConfig(
        # когда аккаунт достигает заданного порога по лимиту лидерборда, 
        # аккаунт перестаёт выбираться для активности.
        # лимит указывается в процентах.
        leaderboard_top_limit=1,
        # практически после каждой транзакции в базу данных заносится изменение баланса.
        # данный критерий отбирает аккаунты, которые вышли за пределы по сожжённому газу,
        # и не берёт их в работу.
        total_costs_limit=0.0075,
        # ежедневный лимит на количество транзакций.
        # максимум можно набрать 75к очков в сутки за транзакции, 
        # все последующие ончейн активности засчитываться не будут.
        # а значит более 750 действий производить просто нет смысла.
        daily_txs_limit=500,
        # какой баланс в $ETH оставлять в сети TAIKO, 
        # если включён модуль вывода баланса из сети на CEX.
        leave_balance_on_taiko_chain=0.011,
        # какой баланс в $ETH оставлять на 'source_chains' при депозите баланса из них на TAIKO.
        leave_balance_on_source_chains=0.0011,
        # бриджить ли баланс из всех 'source_chains' в TAIKO.
        deposit_from_source_chains_to_taiko=True,
        # выводить ли $ETH из TAIKO на 'recipient_chains' и впоследствии на публичные адреса CEX.
        withdraw_from_taiko_to_source_chains=False,
        # какие мосты использовать для бриджей в обе стороны. 
        # доступные варианты: xy, orbiter, hyperlane, gas.zip
        bridges_to_use=['xy', 'orbiter', 'hyperlane', 'gas.zip'],
        # какой минимальный трансфер производить при бридже, 
        # дабы избежать бриджей по 0.00001 $ETH и не сжигать на бридж лишний $ETH.
        minimum_transfer_value=0.001,
        # какой минимальный баланс в $ETH должен быть на кошельке в TAIKO, 
        # чтобы взять его в работу.
        minimum_taiko_balance_to_be_used=0.0001
    ),
    modules=ModulesConfig(
        # все настройки указываются для одного цикла для одного аккаунта.
        # софт перед стартом генерирует для каждого аккаунта выбранные модули в случайном порядке и выполняет их.
        # когда все задания выполнены, происходит заданная в 'user_data/config.py' пауза между циклами.
        # после чего софт заново создаёт маршрут для каждого аккаунта отдельно и начинает уже его.
        # затраты указаны для одной транзакции.
        
        # количество 'wrap/unwrap' транзакций, затраты $0.01.
        wraps_range=(0, 10),
        # количество минтов на 'conft.app/launchpad/community', затраты $1.
        conft_mint_range=(0, 0),
        # количество минтов на 'omnihub.xyz/collection/taiko/omnihub-x-taiko-on-galxe', затраты $0.3.
        omnihub_mint_range=(0, 0),
        # количество голосований на 'rubyscore.io/dashboard', затраты $0.01.
        rubyscore_votes_range=(0, 10),
        # количество транзакций селф-трансферов $ETH, затраты $0.01.
        self_transfer_range=(0, 3),
        # для каждого кошелька генерится пустой уникальный бёрнер, 
        # с которым взаимодействует только один кошелёк.
        # приватные кошельки от бёрнеров записываются в базу данных в таблицу 'burner'.
        # количество трансферов на пустой кошелёк и обратно, затраты $0.01.
        burner_transfer_range=(0, 7),
        # модуль игры на brigadegame.io.
        # набор 5-7 транзакций по типу вращения колеса, чекина или выбора случайной капсулы.
        # затраты на каждую из транзакций $0.01. 
        brigade_game=True,
        # запрос бесплатных игр на 'crackandstack.com/#mines', затраты $0.01.
        crack_x_stack_range=(0, 5),
        # старт игры 2048 в 'zypher.game/2048', затраты $0.7.
        zypher2048_range=(0, 0),
        # ежедневный чекин в '0xastra.xyz', затраты $0.01.
        oxastra_boost=True,
        # создание пустого контракта, затраты $0.1.
        contract_deploy_range=(0, 1),
        # минт 'entry pass' на 'blazpay.com/entry-pass/taiko', затраты $0.2.
        blazplay_mint_limit_per_account=(1, 1),
        # минт 'standard elements' на 'openalchi.xyz/game', затраты $1.
        openalchi_mint=True,
        # случайный выбор продолжительности лока $TAIKO на 'taikodrips.xyz'.
        # доступные варианты: 60, 91, 182, 365.
        taikodrips_lock_in_days_range=[60, 91],
        # диапазон количества токенов $TAIKO для стейка на taikodrips.xyz.
        taikodrips_stake_amount_range=(10, 11),
        # количество транзакций 'gm' на 'app.rhino.fi/realm/trackers/TAIKO/deploy-and-interact'.
        # взаимодействия производятся через контракты в 'user_data/rhino.txt'.
        # если файл пустой, модуль будет игнорироваться, затраты $0.15.
        rhino_gms_range=(0, 3),
        # лимит на количество деплоев контракта на 'app.rhino.fi/realm/trackers/TAIKO/deploy-and-interact'.
        # после создания нового контракта он дозаписывается в 'user_data/rhino.txt', затраты $1.
        rhino_deploy_limit_per_account=(1, 1),
        # даёт разрешение на использование случайных токенов случайным протоколам.
        # после окончания модуля отзывает все апрувы и кошелёк остаётся совершенно чистым.
        # затраты $0.01 за каждую транзакцию.
        random_allowance_range=(0, 3),
        # количество депозитов и моментальных выводов через lend.meridianfinance.net,
        # затраты $0.1 за deposit и withdraw.
        meridian_range=(0, 1),
        # количество депозитов и моментальных выводов через hana.finance,
        # затраты $0.1 за deposit и withdraw.
        hana_range=(0, 1),
        # количество деплоев контракта на owlto.finance/deploy, затраты $0.01.
        owlto_range=(0, 5)
    )
```
